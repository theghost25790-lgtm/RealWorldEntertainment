# Privacy

Project 2088 is currently distributed as a standalone APK.

The public repository and release downloads are hosted by GitHub and are therefore also subject to GitHub's own privacy practices. SideQuest use is subject to SideQuest's applicable policies.

Project 2088 does not currently operate a proprietary advertising-profile system. If optional analytics, online advertising delivery, accounts or other network services are introduced, this notice must be updated before those features are released.

Questions may be submitted through the repository's Issues section without including private or sensitive information.
