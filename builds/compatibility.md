# Compatibility

Project 2088 is primarily developed for Meta Quest 2 and tested for Meta Quest 3.

Compatibility must be recorded separately for every release because performance, Android requirements and gameplay systems may change between builds.

Recommended release notes:

- Tested headset models
- Required free storage
- Installation or upgrade behaviour
- Save-data compatibility
- Known performance issues
- Controller requirements
- Whether the build can coexist with another version
