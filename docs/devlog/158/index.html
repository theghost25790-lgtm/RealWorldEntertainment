BUILD 098 —
THE ARCHIVE GROWS

Project 2088 Devlog 158 records the move from isolated releases toward a preserved, traceable development system.

RWE-P2088-DEV-15813 SEP 2026PUBLISHED

Development record

This week strengthened Project 2088's public preservation and the infrastructure around the game. Builds 97B and 98 were published as GitHub releases, extending the preserved build line beyond 96D.

The RWE website is now the public home for builds, devlogs, Signals, the Visual Archive, Founders, locations and submissions. Behind the runtime build, RWE Bridge planning advanced toward a dedicated private QA application with a mobile-first PWA direction, permanent deep links and durable server-side session and event history.

The next milestone is traceability: document exact changes between 96D, 97B and 98, complete a recorded Quest 3 regression pass for Build 98, define the minimum Bridge event envelope and prove one end-to-end QA session path.

Confirmed movement

  • Build 97B preserved as a public GitHub release.
  • Build 98 preserved as a public GitHub release.
  • Build 96D remains in the preserved release line.
  • The public RWE website and build archive are active.
  • QA direction separated into a dedicated private application.
  • Deep linking and durable session/event history became first-class architecture requirements.

Next priorities

  1. Write an authoritative 96D → 97B → 98 changelog.
  2. Complete and record a Quest 3 regression pass for Build 98.
  3. Define the minimum Bridge event envelope.
  4. Prototype one end-to-end QA session timeline and flagging path.
  5. Validate one AI combat blocker in a repeatable test arena.
