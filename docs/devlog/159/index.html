BUILDING
THE BRIDGE

Project 2088 begins formalising one language across Unreal Engine, RWE Bridge, QA and future services.

RWE-P2088-DEV-15915 SEP 2026PUBLISHED

Development record

A significant amount of Project 2088 development is now happening beneath the visible game.

The RWE Bridge architecture has continued to take shape. The core hierarchy is now:

PROJECT → BUILD → INSTALLATION → SESSION → EVENT

Rather than individual systems inventing their own terminology, Project 2088 will increasingly describe gameplay through a shared canonical event language. A weapon being collected, an NPC dying, a session beginning, an achievement unlocking or a player entering a location should all become events understood by Unreal Engine, RWE Bridge, QA and future services.

Canonical architecture

The Canonical Event Registry now includes build and session registries, lifecycle events, compatibility handling and explicit schema and Bridge version information.

Weapon architecture is also formally documented: BP_Pistol remains the parent class for Project 2088 firearms and BP_Mag remains the parent class for magazines. Generic systems should reference those parent contracts where possible rather than depending on individual variants.

Implementation order

  1. Naming and identifiers
  2. Builds and sessions
  3. Player
  4. NPCs
  5. Weapons and magazines
  6. Combat
  7. Locations
  8. Bridge
  9. QA
  10. Achievements

The goal: one language across the entire RWE ecosystem.
