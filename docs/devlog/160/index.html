Development record

Project 2088's internal QA tooling has grown beyond the point where it makes sense to hide it inside the normal RWE administration interface.

QA is becoming its own application, with dedicated views for builds, sessions, testers, QA flags, feedback, adaptive interviews, achievements, performance, evidence and administration.

Two surfaces

Mobile and tablet: a lightweight PWA-style interface suited to active testing.

Desktop: deeper analytical tools for session investigation, build comparison and evidence review.
