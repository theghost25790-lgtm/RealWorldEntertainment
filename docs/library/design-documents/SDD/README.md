- audio philosophy

- voice direction
- hostility voice progression

- triggers, cooldowns and priority
- voice production pipeline
- filename standards
- Quest-focused audio implementation constraints

## Core principle

**The player should hear the world before the world explains itself.**

## Construct direction

Construct voices should become more certain as hostility rises, not theatrically angrier.

**Do not perform anger. Perform certainty.**
