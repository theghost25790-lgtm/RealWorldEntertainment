# Save Data and Version Changes

Project 2088 is under active development. Save formats and storage behaviour may change between builds.

Until a build is explicitly documented as save-compatible:

- Treat each release as potentially incompatible with earlier saves.
- Assume uninstalling the application may remove local save data.
- Do not rely on a development build as permanent storage.
- Read the individual release notes before replacing an installed build.

Future releases should state whether installation updates, preserves, migrates or resets existing save data.
