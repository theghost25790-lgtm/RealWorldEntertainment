# Troubleshooting

When reporting a problem, include:

- Project 2088 build number
- Headset model
- Whether installation used USB or wireless SideQuest
- The exact error message
- Whether an older Project 2088 version was already installed

Do not post passwords, signing keys, private account information or unnecessary device identifiers.

## Common checks

- Confirm that the APK finished downloading.
- Confirm that SideQuest recognises the headset.
- Confirm that the headset has sufficient free storage.
- Check whether an existing build must be removed first.
- Restart SideQuest and reconnect the headset.
- Use the bug-report or installation-help issue template if the problem continues.
