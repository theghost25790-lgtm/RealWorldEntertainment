# Glossary

Last updated: 27 September 2026

## RWE

**Real World Entertainment**

Umbrella entertainment/project identity and home of Project 2088.

## RWS

**Real World Studio**

Web/digital services arm.

## Project 2088

Fictional science-fiction game/world project set primarily in Britana in 2088.

## The Bridge

Shared data/event/integration layer connecting Project 2088 runtime evidence with QA, achievements, websites and future services.

## QA

Separate quality-assurance product/interface for tester profiles, sessions, timelines, events, feedback, flags, achievements and later crash/performance evidence.

## QR Site

Lightweight mobile site designed for QR and NFC entry points.

## Britana

Project 2088 name for Great Britain in the 2088 setting.

## Construct

Infrastructure-building and maintenance corporation/faction in Project 2088.

## Anamika

Project 2088 pharmaceutical/augmentation megacorporation.

## Lockhead

Project 2088 weapons-manufacturer analogue.

## Cell Health

World simulation measure of civic resilience and ordinary-life functioning.

Separate from faction control.

## Conflict Pressure

Separate world-simulation measure covering faction pressure, violence, scarcity, isolation, player-caused pressure and event triggers.

## Canonical Event

A registered event definition used by The Bridge.

Events record facts rather than commands.

## Canonical Record

A stable cross-system record identity intended to remain permanent.

## Runtime Instance ID

Temporary identity for a spawned/session-specific occurrence. It must not automatically become a permanent canonical record.

## BP_Pistol

Parent firearm Blueprint class used as the shared firearm contract.

## BP_Mag

Parent magazine Blueprint class used as the shared magazine contract.
